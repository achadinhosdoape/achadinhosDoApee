ACHADINHOS DO APÊ — CAPA 2009 x 783

A imagem da capa usada em .hero .hero-image é exatamente 2009 x 783 px.

No CSS, a proporção é preservada com:
.hero-image { width: 100%; aspect-ratio: 2009 / 783; ... }

Isso faz a capa se adaptar à largura da tela sem deformar a arte.
No celular, a mesma proporção é mantida para preservar o layout da capa.
